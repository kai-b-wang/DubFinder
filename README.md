# DubFinder

An indoor "street view" wayfinder for UW campus buildings, starting with the first floor of Mary Gates Hall.

## Overview

Google Maps shows what buildings look like from the outside, but not the inside. Students, especially freshmen, often struggle to find the right classroom. DubFinder is a web prototype that lets users explore a building's hallways through photos, moving between scenes by clicking directional arrows, or picking a room number from a side menu to be guided there right away.

## Features

- Photo-based hallway viewer, similar to Google Street View
- Directional arrows to move between connected photos
- Side menu of rooms (e.g. Suites 134, 141, 171) that jumps to that room's scene

## Tech Stack

- TypeScript (plain, or with Three.js if we need more advanced viewing)
- HTML/CSS
- LLM-assisted coding for building the prototype
